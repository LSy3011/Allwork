## 0. 结论

**同一套编译方法（配置-only 准入 → 通用 SMT 调度 → ADR-057 分段器 →
ADR-061 统一 LCS 程序链 → VCS + 独立参考对账）在零生产代码改动下处理了一个
结构性更复杂的计算**：horner_v3u（II=6、6 级串行依赖链、计算队列多槽、
三路 x 流滞后 0/2/3、四参数 + 常量 + 单输出）。五步证据链全部落档，
唯一一次规则改动（C-H 公式化）按用户立法序执行并有失败形态留档。

**对外宣称边界**：本结论的适用域 = §2 第三档所列；不覆盖任意 II、任意
多槽组合、多 SMC、归约/矩阵/原地更新、ragged tail、host 自主闭环与上板。

## 2. 结构覆盖矩阵（三档分层，用户裁定口径）

### 第一档：已测案例（具体 yaml 配置 × 规模，VCS 级实证）

| 算子 | 公式 | II | 计算槽 | 参数 | 单段容量 n_max | 实测规模（链） |
|---|---|---|---|---|---|---|
| add | x + other（逐元素） | 1 | fpadd 单槽 | 无 | 240（既有） | 4/8/60（V1 + 冻结回归） |
| scale_sum | alpha * (x + other) | 2 | fpadd 单槽 | 1（stride0 标量） | **240**（rtovr-14 恰 128 行） | 4/8/60/240 单段；244/480 两段；统一 LCS 16/60/240/244 |
| horner_v3u | ((c0·x + c1)·x + c2)·x + c3 | **6** | **fpadd 3 + fpmul 3（多槽首证）** | **4（stride0 标量）** + 常量 | **68**（七队列恰 128 行） | 4/8/60（V1）；68 单段顶格；72 两段；统一 LCS 8（3 段程序）/72（4 段程序） |

### 第二档：已证形态（由第一档案例正面钉死的结构性能力）

1. **公式子集**（ADR-056 §A）：无状态、非原地、单输出逐元素、fp32、单 SMC、
   顺序执行——三算子同子集，配置-only 准入成立。
2. **II 多样性**：II=1/2/6 三值实测 VCS 通过（II 普查基线 28/36 解出，
   VCS 实证仅这三值）。
3. **计算队列多槽**：单队列内多有效槽（fpadd[0,2,4]/fpmul[1,3,5]）调度与
   发射正确——add/scale_sum 恒单槽，horner 为首证案例。
4. **多流滞后读**：同一输入 x 的三条读流、迭代滞后 0/2/3、各流读数恰
   R_q=span+m、死读绕回（mod 256）由活性排除。
5. **多参数 stride0 标量驻留**：4 参数分置 4 bank（line0 四 lane 全等 ∧
   line1.. 全零形态正面取证）+ 常量 bank 同形态。
6. **超容量自动分段**：ADR-057 分段器对两算子三规模（244/480/72）切段正确；
   跨案例一致性（n=72 stage_0 ≡ n=68 单段，18/18 hex 逐字节一致）。
7. **统一程序链**：LOAD→COMPUTE(×K)→STORE（K=1：scale_sum 16/60/240、
   horner 8；K=2：scale_sum 244、horner 72），C-L/C-S/C-H/C-W 检查栈全过。
8. **响亮拒绝边界**：n%4≠0、超 bank 容量、bank 交叠、公式叶缺/布局多载、
   参数非驻留形态——均 RED 且不发布。

### 第三档：一般化适用范围（可诚实宣称 vs 明确不外推）

**可宣称**：在 ADR-056 §A 公式子集内，「新公式 = 新 yaml 配置」即可经同一
通用链路（无算子名/张量名特判）完成准入、调度、分段、程序装配与 VCS 验证；
C-H 独立参考对任意有序 AST 可解析公式按同一 machinery 求值。

**明确不外推**（未证，逐条登记）：
- 任意 II 值（实测仅 1/2/6；II>6 的队列深度/槽位组合未验）；
- 任意多槽/多单元组合（实测仅 horner 一种 3+3 形态）；
- 任意参数个数与布局（实测 ≤4 参数 + 1 常量 bank；bank 数上限未探）；
- 多 SMC、ragged tail（n%4≠0）、归约/矩阵/原地更新（ADR-061 非目标原样保留）；
- host 自主完成闭环（同步 = TB 辅助；F6 线既知边界）；
- 上板（本仓库编译器产物无任何上板记录；RTL_VERSION 0x00042200 仅为板端
  期望值口径）。
