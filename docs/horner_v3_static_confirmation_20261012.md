## 1. 公式与有序 AST【实测 A】

- 公式原文：`((c0 * x + c1) * x + c2) * x + c3`（3 乘 + 3 加，6 级串行链；
  单流式输入 x + 4 驻留参数）。
- 有序 AST 签名：`(add (mul (add (mul (add (mul c0 x) c1) x) c2) x) c3)`；
  求值拓扑序（后序左先）6 节点逐字符合 Horner 顺序。
- `parse_ordered_formula` PASS（张量名集 = {x, c0..c3}；reserved={y, constants}）。

## 2. 有序浮点语义确认【实测 A/B/C】（用户令前置条件）

三层比对，同一「交换律层规范化签名」（孩子排序——fp32 加/乘逐位交换安全，
结合性改变会判 MISMATCH）：

| 层 | 对象 | 结果 |
|---|---|---|
| A | 文本 → 有序 AST（`ordered_ast.py`，独立参考锚） | 基准签名 |
| B | SymPy 规范化树（编译器前端实际消费，`srepr` 落档） | **MATCH**——SymPy 未做重结合/Pow 化，仅交换律级互换 |
| C | DFG 计算树（post-bypass MIR，沿 `rtovr_deps` 回溯 6 计算节点；链线性 = 每非根节点恰 1 计算消费者；根唯一 = y_0_a1） | **MATCH**——调度对象 ≡ 文本有序公式（模安全交换） |

端口序核查（`depends_on` 声明序）：链上每节点 = `(参数或 x, 上游计算结果)`，
即 c1/c2/c3 与 x 均落 S0、链值落 S1——与文本 `((c0*x+c1)*x+c2)*x+c3` 逐节点
对应（S0/S1 内交换为逐位安全）。

运行时锚（步②起生效，此处登记机制存在性【源码】）：独立参考 =
`rg.evaluate(ordered_root)` 按有序 AST 逐节点 fp32 求值
（`run_v1_verify.py:590-595`），三区比对/bit-exact 以其为锚——有序语义的
最终裁决在步②④的 VCS 比对中强制执行。

## 3. 调度解与槽占用【实测 D】

`solve_with_units(MII=1, MAX_II=64)` 一次命中 II=6 SAT（MII 资源下界 = 6，
VIN0 6 ops）。18 队列；槽位 = t mod II，span_q = max_t//II − t_min//II
（assembler.py:218/395-396 原式）：

| queue | ops | slots | span_q | 备注 |
|---|---|---|---|---|
| **fpadd** | 3 | [0,2,4] | 4 | **计算队列三有效槽** |
| **fpmul** | 3 | [1,3,5] | 4 | **计算队列三有效槽** |
| rtovr-14 | 6 | [0..5] | 4 | **满槽 6/6** |
| vin0 | 6 | [0..5] | 4 | **满槽 6/6** |
| rtovr-3/4 | 3 | [0,2,4] | 4 | |
| rtovr-5/6 | 3 | [1,3,5] | 3 | |
| ur-r0 | 3 | [1,3,5] | 3 | x 三次重读 |
| ur-r1 | 2 | [0,2] | 3 | 参数读 |
| ur-r2/ur-r3/vin1/vout0/ur-w2/rtovr-15/16/37 | 1 | 单槽 | 0 | ×8 |

正面确认：**II=6 > 2** ∧ **同计算队列多有效槽（fpadd/fpmul 各 3）**——两条独立
满足用户步①结构判据。对照：scale_sum/add 计算队列各 1 op = 单槽（本探针
control 输出 FPADD/FPMUL count=1）。

与预检互证：II/队列数/槽位/满槽队列逐格一致
（`precheck_complex_formula_20261010.md` §3.1-③【归档级一致】）。

## 4. 域闸【实测 E/E2】——一过一拒

- 静态道：`static_domain_check` ok=True，无诊断（与预检 §3.1-⑤ 一致）。

  （`run_v1_verify.py:601-607`），**现 test_data 参数值必然响拒**。

  （量化方向向内，实测通过）。改动不改公式结构，有序语义结论不受影响。
  新参数下逐节点值域手核（x∈[0.1,1] 两端点）：中间值 ∈ [−0.25, 0.375]、
