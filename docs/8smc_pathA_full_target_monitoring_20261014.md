# 路径 A：8-SMC 全目标监测（隔离 TB 实现）设计稿与验收口径

> 依据：用户 2026-10-14 令「同意启动路径 A，全目标监测先在隔离 TB 中实现，不直接改原树」。
> 性质：**验证资产（TB）设计稿**，不含功能 RTL 改动。实施位置 = 隔离副本
> `~/u280_sim_v422_pA_20261014/`（源码子集 128 文件与原树逐字节同一，TB 为该树内
> 唯一计划改动件；原树 `~/u280_sim_v422` 与既有包零改动）。
> 本轮边界（用户原文）：不增加规模、不碰板卡、不改功能 RTL、不扩大到超过现有在飞深度。

## 0. 为什么需要它（路径 B 不足以升级的缺口）

| 完成条件 | 路径 B 能给的 | 缺口（路径 A 补） |
|---|---|---|
| LOAD→COMPUTE | 「信用链若逐级配对」的结构论证 | **逐目标 COMPUTE 首读时序**；延迟某个非零 SMC 时不提前放行的实证 |
| COMPUTE→STORE | LSU 信用链不覆盖计算结果写回 | **逐 SMC 计算末写（UR 落位）检查** |
| STORE→结束 | STB/STBAXI 信用汇总 | **逐通道实际写入 + 写响应完成**（本地信用不保外部写完成） |

## 1. 观测面（步骤一：只加探针，不改任何门控）

现有原树 TB 的观测面缺口（只读逐行核过）：

| 事件 | 原树 TB 现状 | 本轮新增 |
|---|---|---|
| UR 写（LOAD 落位 / 计算落位） | `ur_write_trace.log` **已逐 SMC**（URA 通道 + CRU 提交管两条路径） | `pa_ur_wr_trace.log`：同信号 + **类标注**（`ura` = LDB 装载落位 / `cru` = 计算提交落位），便于逐目标分类 |
| COMPUTE 读（CRU 读口） | `ur_read_trace.log` **仅 SMC0**（历史 smc_id_en=0 情形下完备） | `pa_ur_rd_trace.log`：**SMC0..7 全抽**（`w_ur_re_{0..3}_eff` × 8 颗） |
| STORE 读（STB URA 读口） | `stb_ur_read_trace.log` **仅 SMC0** | `pa_stb_rd_trace.log`：**SMC0..7 全抽** |
| 信用脉冲 | 仅聚合上报点 `i_crd_*`（= chain[0]） | `pa_crd_trace.log`：**crd_{ldb,ldbaxi,stb,stbaxi}_chain[0..7] 八个位置逐拍抽头**（`{inst_id, done, valid[, err]}`，只读） |
| HBM 写 | `hbm_write_trace.log` **已逐 SMC**（8 个显式 SRAM 宏探针） | 沿用（不再复制） |
| 写响应（B） | `g3_hbm_bresp_cnt` **仅 ds2 = 通道 0** | `pa_bresp_trace.log` + 逐通道计数：**bmc_ds2..ds9（通道 0..7）B 握手逐笔** |

全部为 observe-only（只读 DUT 信号，不 drive、不改时序），默认常开但不影响功能路径。
共享 `iq_probe_cycle` 锚（与原树探针同源），保证跨文件逐拍可比。

## 2. 全目标放行条件（步骤二：补齐门控时实现）

按**实际活动目标集合**（`partition.active_smcs`）判断，不只检查 SMC0：

1. 对每个活动 SMC k：`first_compute_read(k) > last_load_write(k)`；
2. 对每个活动 SMC k：`first_store_read(k) > last_compute_write(k)`；
3. 最终 dump 晚于**全部活动目标**的 HBM 窗口写入落位 **且** 全部通道所需 B 响应已完成。

门控信号一律取自 §1 的 TB 侧记账（位掩码/计数，重复事件不膨胀），超时即 `$fatal`
（沿用 ADR-060 §2.2-3：超时是 RED，禁止调大上界消红）。

## 4. 证据口径与限制

- 本线证据为 **VCS 仿真**；不继承 F6 结论、不推断板端、不外推硬件不可恢复性。
- 逐 SMC 读/写/信用抽头是**观察**，其存在不表明 DUT 行为改变；步骤一与步骤二各留
  TB sha256（步骤一的「原门控下实际先后关系」必须在步骤二改动前取到并留档）。
- 「信用齐」仍不等于「外部写完成」（用户钉死）：STORE 侧判据取 HBM 落位 + B 响应。
- 每运行的周期级引用一律取自该运行**自身**日志（不得跨 run 移植时序，含 r2 订正口径）。
