# AIACC 算子物理产物标准模板 (Standard Artifact Samples)

本指南展示了 `Sin` 算子在工业化开发流水线中各阶段生成的标准产物示例。

## 1. 算法时序文件 (algo_timeline.txt)
**生成阶段**: `Synthesizer.solve()`
**核心作用**: 定义全局时钟 $T$ 对应的逻辑点火序列。
**格式说明**:
- `T=<Cycle>`: 物理点火时间戳。
- `Unit`: 分配执行任务的物理 IQ 单元。
- `Payload`: 解耦后的物理指令语义。

## 2. 物理 ACB 安装包 (Physical Bundle)
**生成阶段**: `LIRPacker.emit()`
**存放目录**: `build/<op_name>_audit_phys/`
**标准组件**:
- `sim_config.json`: 定义物理环境（SMC 频率、Bank 初始数据、最大拍数 120）。
- `smc_0/iq_*.hex`: 对应各个端口的物理机器码。
- `smc_0/ur_data/*.hex`: 初始输入向量的流水线预装载图。

---

## 3. 高密仿真轨迹 (timeline_ascii.txt)
**生成阶段**: `SMC_Simulator / TraceRecorder`
**存放路径**: `smc_0/analysis/timeline_ascii.txt`
**审计特征**:
- **脉冲对齐**: `m`/`a`/`L`/`S` 符号必须严格对齐 `algo_timeline.txt` 的 $T$ 坐标。
- **生存过滤**: 仅显示活跃行。
- **降噪标记**: 所有的 NOP 强制显示为 `.`。
