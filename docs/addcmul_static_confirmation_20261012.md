## 0. 结论

**步①通过（带一个核心结构发现与一个方法学发现）**：

1. **三因子乘积的有序语义分歧被正面鉴别并定位**：addcmul 遗留公式文本
   `x + value * t1 * t2` 的有序 AST = `((value·t1)·t2)`，但编译器实际消费
   SymPy 树——`Mul.args` 规范序 `(t1,t2,value)` 经 `lower_mul` 左折叠
   （standard_kernels.py:17-20）→ DFG 实算 `((t1·t2)·value)`。fp32 乘法
   交换安全但**结合不安全**：遗留文本形的**名义语义与编译语义分歧**
   （horner_v3 全二元乘从未触发此类——该类分歧需 ≥3 因子乘积才存在）。
   **处置 = 配置级公式文本对齐**：同一数学函数的等价文本
   `x + t1 * t2 * value` 的文本序恰 == SymPy 折叠序 == DFG 序（三层签名
   互等，§1）。零生产代码改动、零名称特判、零规则改动。
2. **U9 关闭**：fpmul 双计算槽由【推断】升级为【实测（求解器）】——
   两个 FPMUL 节点落在 mod-II 两个不同槽位（观察实例 [0,2] 与 [0,1]，
   槽位身份随模型漂移、双槽属性全实例一致；逐拍发射层实证归步②）。
3. II=3 复现 census 归档值；队列 17 个；无满槽队列。
4. 容量构造预测 n_max=152（m_max=38，四个求解实例数值稳定；束缚队列身份
   ur-r2/vin0 漂移、span 均 4）——**未校准，禁用于准入**，步③ VCS 校准。
5. 方法学发现：Z3 模型挑选随进程状态/代码路径漂移（同脚本三连跑逐字节
   一致，跨路径观察到时刻/槽位差异），**II 稳定、放置不稳**——
   D-control 口径已改为「II 复现断言 + span/L 观察量」，容量校准锚明确为
   发射产物实测而非重解（VARIANCE.md）。

## 1. 有序浮点语义三层比对（核心发现）

| 层 | legacy 文本 `x + value*t1*t2` | aligned 文本 `x + t1*t2*value` |
|---|---|---|
| A. 有序 AST 签名 | `(add (mul (mul t1 value) t2) x)` | `(add (mul (mul t1 t2) value) x)` |
| B. SymPy 签名（同一树，srepr=Add(Mul(t1,t2,value),x)） | 剥 NARY3 标记后 **False**——折叠结合序与文本序实质分歧 | 剥 NARY3 标记后 **True**（NARY3 仅为 3 因子平坦化的机械标记） |
| C. DFG 计算树签名（调度对象本身，post-bypass MIR） | **False** | **True** |

- 两文本 sympify 后为**同一 SymPy 树**（simplify 差 == 0，Mul.args 同序）
  → 共享同一 DFG：对齐不改变编译产物，只改变「文本声明的结合序」使之与
  编译产物一致【实测】。
- DFG 计算链（叶→根）：`FPMUL(t1,t2) → FPMUL(m1,value) → FPADD(m2,x)`；
  计算根唯一、链线性（每非根节点恰 1 个计算消费者）【实测】。
- 既有先例对比：horner_v3 三层全 MATCH（其乘积皆二元，无平坦化余地）；
  scale_sum/add 同样全二元。addcmul 是普查候选中**最短的三因子乘积案例**，
  该类分歧的首次实证。

**对存量 addcmul.yaml 的定性**：该配置从未通过 V2 验收（仅 census 求解记录），
故无已发布错误产物；但其文本序与编译语义分歧属**存量配置缺陷**——登记在案，
不修改（冻结原则），步②以新配置承接，本报告即差异说明。

## 2. 调度解（U9 关闭）

`addcmul.yaml` DFG 经 `solve_with_units(MII=1, MAX_II=64)`【实测】：

- **II = 3**（census 归档值 3 复现 ✓）；队列 17 个。
- **fpmul：2 节点、2 个 mod-3 槽位**（实例 A [0,2]、实例 B/C/D [0,1]）——
  U9「双计算槽」判定由【推断】升级为【实测（求解器）】；fpadd 单槽 [1]。
- 满槽队列：无（对比 horner_v3 的 rtovr-14/vin0 满槽 6/6——addcmul 不触发
  满槽新面）。
- 结构对照：horner_v3 = 同队列 3 槽 × 2 单元（II=6）；addcmul = 单队列 2 槽
  （II=3）——多槽形态谱系增加「双槽单单元」一档。
