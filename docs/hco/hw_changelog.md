## 详细变更说明 (v5.0-S05-B2)
1. **41-bit 微码重构**：确立了由位宽预算驱动的指令胶囊模型。
2. **多维循环引入**：明确了 EMBED_LOOPS (3-bit) 与 INC (4-bit) 的物理位宽。
3. **条件分支能力**：新增 JUMP (1-bit) 字段，为动态 DFG 实现预留物理位。
4. **NOP 物理约束**：明确 NOP 只能使用 LOOPS 扩展，DLY 无效。
