# SMI_IQ 硬件指令字段契约 (V27.4)

## 1. 基础控制字段

| 字段名 | 位宽 | 核心语义 | 专家解读 / 实现策略 |
| :--- | :--- | :--- | :--- |
| **VLD** | 1 bit | 指令有效标志 | `VLD=0` 即为 NOP。注意：NOP 指令不执行 payload (CODE)，但仍受 `LOOPS` 和 `COND` 约束。 |
| **JUMP** | 1 bit | 跳转标志 | 跳转指令不支持 `LOOPS` 和 `DLY`，但在 `COND` 满足时执行。 |
| **EMBED** | 3 bit | 嵌套循环深度 | `0` 为最内层（Kernel 层）。编译器目前主要使用 `EMBED=0`。 |
| **EMBED_END**| 6 bit | 循环结束标志 | 仅在 `EMBED=0` 时有效。标识当前指令是否为某一层嵌套循环的终点。 |

## 2. 循环与调度字段

| 字段名 | 位宽 | 核心语义 | 专家解读 / 实现策略 |
| :--- | :--- | :--- | :--- |
| **LOOPS** | 10 bit | 指令级重复次数 | `N` 代表执行 `N+1` 次。用于单条指令在当前 PC 处的微观循环。 |
| **COND** | - | 依赖等待 | 每次发射前检查对应的 `INST_RDY_IN` 位，用于解决 Slot 间的 Raw 依赖。 |
| **DLY** | - | 发射后延迟 | 指令进入延迟线，`DLY` 拍后才产生物理效应。**注意：NOP 指令不支持 DLY**。 |

## 3. 访存与地址计算字段 (最核心)

| 字段名 | 位宽 | 核心语义 | 专家解读 / 实现策略 |
| :--- | :--- | :--- | :--- |
| **INC** | 4 bit | 循环步进值 | 每一圈迭代地址增加的数值。Bit 6-9, 带符号整数。 |
| **INC_EMBED** | 6 bit | 嵌套增量掩码 | 标识外层循环的 `INC` 是否叠加到当前指令的地址计算中。 |

**地址计算公式：**
$$\text{Final\_Addr} = \text{CODE[Base]} + \text{INC}_0 \times \text{Loop\_Cnt}_0 + \sum_{i=1}^6 (\text{INC}_i \times \text{Loop\_Cnt}_i \times \text{INC\_EMBED}[i-1])$$

## 4. 关键实现原则 (V27.4 物理对齐)

1.  **常数项读取稳定性 (Persistence)**：
    - 即使 `Stride=0`（常数读取），也必须设置 **`INC_EMBED` 非零 (推荐 0x1)**。
    - 原因：模拟器/硬件在 `INC` 且 `INC_EMBED` 均为 0 时可能将其视为“单次静态加载”。为了保证在流水线的每一圈迭代（Iteration）中都能重新触发读取，必须激活地址计算逻辑（即使增量为 0）。
2.  **NOP 时的信号保持**：
    - 当 `VLD=0` (NOP) 时，除了 `vld` 信号为 0 外，发给 SMC 的其他控制信号应与前一拍保持一致，以防止总线抖动。
3.  **启动开销锚点**：
    - 全局对齐基于：`1 拍 INIT + 1 拍 HDR + Body`。
    - 物理启动周期公式：$\text{Absolute\_Cycle} = 2 + t_{smt}$。
