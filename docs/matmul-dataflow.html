核心累加核 · fp16_matmul_k16

单-SMC 单列点积 y = dot(a, b)，16 fp16 = 2 个 K=8 tile。因 8to1 加法树无累加位 → 两级归约：片内 8→1，片间 accumulate。

bank0激活 a16 fp16 · 2 tile
lat 1UR_READ · iq30a_readstride=1 逐 tile
RTOVR→ FP16MUL.S0
bank1权重 b16 fp16 · 2 tile
lat 1UR_READ · iq31b_readstride=1 逐 tile
RTOVR→ FP16MUL.S4567
两路汇入乘法器
lat 5FP16MUL · iq18 inl_fp16mul D0/D1 = S0 × S4 = a⊙b · 8 lane 乘积
load_s0123 / s4567 微指令先 latch s_bank（latch lat 1）
RTOVR · D0→S0, D1→S1
lat 4FP32ADDTREE8TO1 · iq28 p_tile pₜ = Σᵢ aᵢ·bᵢ · 8→1 平衡树 · dst_id=0 锁 lane0 片内归约 · 无累加位
RTOVR · →S0
lat 4FP32ADDTREE5TO1 · iq26 y_0 · 累加器 RESULT += pₜ · accumulate=1（5to1 有累加位） 片间累加 loop-carried · II ≥ 4（跨 tile 自环）
RTOVR · →UR_W0.S · sel=26
lat 1UR_WRITE · iq35out_obj_0
bank5输出 y = dot(a, b)Σₜ pₜ = 155.14395（K16 golden · VCS bit-match）
逐 tile 展开（K16 = 2 tile）。累加器初值 0，每迭代把片内部分和累加进上一迭代的 RESULT：
  • tile 0 → p₀ = a[0:8]·b[0:8]；RESULT = 0 + p₀
  • tile 1 → p₁ = a[8:16]·b[8:16]；RESULT = p₀ + p₁（loop-carried 自环）
  • y = p₀ + p₁ = dot(a, b) = 155.14395
扩 K 只改 tile 数（K24=3 / K32=4 / K2048=256 满 bank），结构与延迟不变，累加环多转几圈。

权重流式前端 · k16_ldb / k128_ldb

计算核与 §01 完全一致；唯一区别——权重 b 不预注入 UR，运行时从外部 HBM 经 LDB 载入 bank1。验真实 LLM 场景（权重 8–33MB ≫ UR 256KB）。

外部 HBMmemory_init1.hex权重 b · 128b/line
AXI 读 · burst
lat 1LDB_AXI · iq51ldb_axi触发 AXI 读 · brst=lines-1（≤15=16 行=K128）
lat 40*LDB · iq50ldb写 UR bank1 · ur_addr=0x1000
↑ 两条 CRU 必须同拍发射 · 经连续流缓冲配对
bank1权重 b（LDB 载入）起始空 · 靠 LDB 填
UR_READ iq31 · ⏳ 依赖 ldb done（相位隔离）
§01 计算核FP16MUL → 8to1 → 5to1 累加逐 tile 点积 + 累加 → RESULT
bank5输出 yK128 = 1246.8252（VCS bit-match）
关键契约（VCS 取证 · ADR-050）。
  • 两条 CRU 同拍发射——写侧 FSM latch 描述符、等 AXI 取回数据后写 UR；错拍 → 不 latch → bank1 全空。
  • line_byte_cnt 是总字节数（非每行），设 16×lines，否则 beat1 写使能塌成 0x0001。
  • 相位隔离：b_read 依赖 ldb，边权 = LDB 保守上界 latency 40（*变延迟 DMA，非固定流水 · DEBT-050-VARLAT）。
  • 单条 LDB 上限 = brst 4-bit ≤15 = 16 行 = K128（AXI burst 位宽）。K>128 多描述符当前 blocked on RTL（写侧缓冲 residue + done-握手 EN_COND=0）。

横向扩展 · fp16_matmul_q（4 列稠密）

单-SMC 满 32 乘：4 权重列 S0–S3 × 广播激活 S4–S7。1 条 FP16MUL 的 8 个 D lane fan out 到 4 条独立加法树 → 一词 4 lane。

bank1–4权重 w0–w34 列 · → S0–S3
bank0激活 aSHIFTUP 广播 → S4–S7
RTOVR · 4 权重列 + 广播激活汇入
lat 5FP16MUL · iq18 inl_fp16mul · 32 乘 D0/1=S0×S4 · D2/3=S1×S5 · D4/5=S2×S6 · D6/7=S3×S7
8 D lane = 4 列各一对
8 D lane fan out → 4 列
ADDTREE8TO1 · dst 0Q0Σ D0,D1
ADDTREE8TO1 · dst 1Q1Σ D2,D3
ADDTREE8TO1 · dst 2Q2Σ D4,D5
ADDTREE8TO1 · dst 3Q3Σ D6,D7

4 条加法树共用 iq28，SMT 串行化（dst_id 0→1→2→3 各写一 lane）

bank5 · 一词[Q0, Q1, Q2, Q3]Q[c] = dot(a, w_c) · 4 lane 稠密
与 §01 的关系。Q 把 §01 的 MUL → 8to1 段横向复制 4 份（4 列并行），但 不做片间累加——每列 K=8 单 tile，直接 8→1 出一个标量。点积可交换 → 广播激活到 S4–S7、权重列占 S0–S3，与硬件钦定布局数学等价。
05

N 维广播 · fp16_matmul_n（8-SMC）

同一 Q 核 × 8 SMC 并行。单套全局指令流（ADR-022/023）+ per-SMC 数据：激活经 SHIFTUP 广播到 8 SMC，每 SMC 用本地权重列算，partitioned 输出。跨-SMC 只广播、无 sum-reduce（ADR-025）。

bank0（每 SMC）激活 a共享同一套 iq_*.hex 指令流
SHIFTUP 广播 · smc_id_en=all
SHIFTUP · broadcast=1激活广播到 8 SMC跨-SMC 数据搬运（DST datapath）· 无求和广播 · 非 reduce
fan out → 8 SMC（各持本地权重列）
SMC 0Q 核本地 w · → y₀[0:3]
SMC 1Q 核本地 w · → y₁[4:7]
SMC 2Q 核本地 w · → y₂[8:11]
···
SMC 7Q 核本地 w · → y₇[28:31]

每 SMC = 一个 §04 Q 核（4 列）· 8 SMC × 4 = 32 输出列 · 各自 partitioned 落本地 bank5

bank5 · 每 SMC 独立partitioned 输出y = [y₀ ‖ y₁ ‖ … ‖ y₇] · 无跨-SMC 求和
为什么无跨-SMC reduce。硬件 matmul = N 维广播 + 每 SMC 本地列点积（reduce 全在 SMC 内 8to1/5to1）。跨-SMC 只有 SHIFTUP 广播搬数据，无加法树（ADR-025）。SHIFTDN 仅用于串联 matmul 的结果收集/拼接（纯搬运）。matmul_parallel_n / fp16_matmul_n 均 8/8 bit-perfect。
