# Golden APB 基准值 (PVO 专属)

> PVO 在每个算子首次通过验证后，在此记录基准拍数。
> 硬件变更后，对比新拍数与此基准，判断是否退化。

| 算子 | 基准拍数 | hw_spec MD5 | 日期 | 备注 |
|:--- |:--- |:--- |:--- |:--- |
| sin | 待定 | 待定 | - | 首次合成后填入 |
| exp | 待定 | 待定 | - | 首次合成后填入 |
| atan2 | 待定 | 待定 | - | 首次缝合后填入 |

## 判定规则
- hw_spec MD5 相同 + 拍数增加 = **退化**（必须排查）
- hw_spec MD5 不同 + 拍数变化 = **正常**（记录新基准）
